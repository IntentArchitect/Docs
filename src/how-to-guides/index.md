# How-to guides

Each guide here shows you how to do one thing in Intent Architect, in a short set of steps.

- [Run several agents at once](xref:how-to.run-several-agents-at-once) - start a second task while the agent is still working on the first, or keep it away from your uncommitted work, by giving each chat its own copy of the code on its own branch.
- [Work across related codebases](xref:how-to.work-across-related-codebases) - give the AI agent code outside your solution, such as a frontend or a shared library, to read for context or change as part of the same task.
